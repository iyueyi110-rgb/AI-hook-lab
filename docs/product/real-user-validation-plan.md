# 真实创作者验证计划

> 状态：待执行。当前仓库没有可验证的真实参与者或任务记录，本文只定义未来研究流程，不形成用户效果结论。

## 目标

验证“候选看起来不错”能否转化为“创作者愿意为当前主题选择、修改并实际发布”，而不是继续增加离线模型分数。

## 执行材料

- [真实创作者研究执行包](real-user-research-kit.md)：招募、筛选、知情同意、主持脚本、观察规范、退出撤回与脱敏流程。
- `outputs/stage6-real-user-validation/real-user-validation-workbook.xlsx`：参与者、任务、逐 Hook 反馈、指标汇总、数据质量与字段字典。工作簿当前为空白模板，所有汇总显示“待录入”，不得解释为研究结果。
- 少于 30 个有效完成任务时，只报告观察与整数计数；只有 `publish_followup_authorized=true` 的完成回访任务才具备进入实际发布采用率计算的资格。

## 参与者与招募

- 招募 5–8 名近一个月持续创作、能说明主平台和内容类型的创作者。
- 每位参与者近 30 天至少完成 3 次公开或内部内容发布，不招募只进行一次体验的围观用户。
- 覆盖至少两个主平台和两类内容类型；样本不足时只报告计数，不做平台间百分比比较。
- 研究开始前说明记录字段、脱敏方式、退出权利和图片处理方式；不收集姓名、手机号、邮箱、账号口令或未授权原文。

## 任务流程

1. 每人使用自己的真实主题完成至少 3 个任务，目标累计不少于 30 个完成任务。
2. 每个任务依次完成结构化输入、候选比较、最终选择、必要改写和使用方式确认。
3. 采用现有反馈枚举记录 `direct_use`、`light_edit`、`heavy_rewrite` 或 `reference_only`，不把“收藏”自动解释为采用。
4. 放弃或仅参考时，使用现有原因标签记录主题不相关、内容太泛、平台不匹配、语气不匹配、标题党风险等原因。
5. 只有用户明确同意回访时才记录实际发布结果；未授权任务不进入实际发布采用率分母。

## 最小记录字段

| 类别 | 必需字段 | 约束 |
| --- | --- | --- |
| 任务关联 | 匿名参与者 ID、`taskId`、时间、Prompt 版本 | ID 不含个人信息，时间带时区 |
| 创作上下文 | 平台、内容类型 | 不公开原始敏感主题或未授权文案 |
| 任务状态 | 是否完成、是否看到完整候选 | 未完成任务不进入采用率分母 |
| 人工结果 | 最终选择、使用方式、原因标签 | 使用现有白名单枚举，不提交自由敏感文本 |
| 发布回访 | 是否授权、是否确认发布 | 未授权或失联必须排除并单独报告 |

## 数据质量与排除规则

- `real_user`、`evaluation_set` 和 `simulation` 不跨来源合并。
- 缺少 `taskId`、Prompt 版本、完成状态或来源的记录不得进入结果性指标。
- 同一任务只能有一个最终选择；重复事件按稳定事件 ID 去重，不用最后一次写入掩盖冲突。
- 报告同时给出任务覆盖率、反馈响应率、生成完成率、整数分子分母和 Bad Case 分布。
- 当前公开 CSV 分析器仍按逐 Hook 记录复算收藏和测试内选择；实际使用方式与发布回访只有在对应脱敏数据契约和计算脚本完成后才能形成公开数字。

## 成功判断

- 先建立任务完成率、任务级选择率、反馈覆盖率和改写分布基线，不预设夸大的提升目标。
- 将“实际发布采用率”作为长期北极星候选，但只有获得发布追踪授权的样本进入分母。
- Bad Case 优先关注主题锚定不足、表达泛化、平台语气错配、标题党和事实可信度。
- 真实测试、离线评测和模拟数据继续按来源隔离，不跨来源合并百分比。

## 停止与升级条件

- 少于 30 个有效完成任务时，只输出观察和计数，不输出稳定比例或 Prompt 升级结论。
- 任一改动必须绑定假设、Prompt 版本、目标指标、护栏和停止条件。
- 真实选择证据可以决定交互与研究优先级，但不能替代完整离线盲评形成 Prompt 升级结论。
- 出现隐私、事实可信度或高风险标题党问题时，先停止相关能力扩展并修复护栏。
