# 策略卡管理员操作手册

1. 在运营分析 Agent 的建议中，只对 `strategy_candidate` 点击“创建策略草稿”。
2. 在 `/admin/dashboard/strategies` 检查范围、指导、假设、服务端固定的来源与数据局限。
3. 提交审核后内容不可编辑。如需修改，克隆为下一版本草稿并查看结构化版本差异。
4. `approved_experiment` 只允许进入离线评测。为每个平台/内容类型范围分别创建 20 主题 Live 盲评。
5. 两名评测员完成独立评分和 A/B 定案；有分歧时由独立裁决员处理。
6. 管理页显示全部范围的最新证据门禁。只有状态显示“全部范围通过”时，激活按钮才可用。
7. 激活时设置 7–90 天有效期。到期前重新收集证据并人工决定是否克隆新版本，不自动续期。

观察性看板只能用来发现使用信号和风险，不能证明策略提升。多个策略范围重叠时，创作者每轮最多选择一张；管理员应优先保留指导互不冲突、证据更新较新的版本。

出现高严重度 Bad Case 增加、哈希异常、范围错误或证据过期时，应立即归档，随后克隆新版本修订，不直接覆盖历史。
