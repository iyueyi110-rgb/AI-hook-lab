## 人工三端复测

以下结果必须由产品负责人在投递前使用真实设备或浏览器填写；自动检查不能替代人工验活。

| 场景 | 日期 | 结果 | 异常与处理 |
| --- | --- | --- | --- |
| 手机流量访问 | 待人工填写 | 待验证 | 验收首页、经典生成主路径和错误态 |
| 无痕浏览器访问 | 待人工填写 | 待验证 | 验收无缓存、无登录状态下的首屏与主路径 |
| 桌面浏览器主路径 | 待人工填写 | 待验证 | 验收输入、候选生成、选择与反馈；不得提交真实敏感内容 |

三项均通过且无密钥、隐私或错误态问题时，才可恢复 README 与 GitHub Website 在线入口。任一场景失败或未完成时，招聘入口只使用 GitHub、截图和 60–90 秒录屏。

## 投递前检查

1. 使用手机流量、无痕浏览器和桌面浏览器分别访问。
2. 确认 30 秒内能理解产品并进入经典生成主路径。
3. 检查无 Key、上游失败、请求超限和移动端错误态。
4. 录制 60–90 秒备用演示：问题与用户 → 输入 → 10 个候选 → 选择/反馈 → 评测边界。
5. 地址不稳定时，简历优先使用 GitHub、截图和录屏，不放失效链接。
