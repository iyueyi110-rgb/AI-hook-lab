# 创作者策略卡帮助

策略卡是已经过管理员审核和固定盲评的可选创作建议。它不会代替你的创作简报，也不会改变创作 Agent 的确认、改写和最终采用流程。

- 确认简报或把经典候选带入“继续打磨”前，系统最多展示 5 张与当前平台和内容类型精确匹配的策略。
- 你可以选择一张，也可以明确选择“本轮忽略策略”。
- 策略建议受众与当前任务受众会并列展示。系统不会自动判断两者是否匹配，请自行核对。
- 绑定后，同一轮不能切换策略。结果区会保留策略版本标记。
- 生成后可以反馈“有帮助”“无帮助”或“不适用”。不适用原因只使用平台、内容类型、受众、语气、主题和其他等枚举，不收集自由文本。
- 有时看不到策略，是因为没有匹配且仍在有效期内的激活版本，或管理员临时关闭了新策略绑定。
